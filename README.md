# Kurai Healing

Цифровая экосистема звукотерапии, обучения и гармонизации, вдохновленная традициями Уральских гор. 

### Особенности проекта:
* **Медитативный плеер:** Генерация акустических частот 432 Гц в реальном времени.
* **Интерактивный симулятор:** Практика игры на традиционном курае прямо в браузере.
* **Каталог и медиатека:** Открытые видеоуроки по дыхательным техникам и звуковые сеансы.

### Как запустить локально:
Скачайте файл `index.html` и откройте его в любом современном веб-браузере.
